- **样式来源**：样式入口按顺序引入 Element Plus → `design-system/dist/index.css` → 桥接 `{{BRIDGE}}/{element-plus.css, iconpark.css}` → 配方层 `{{BRIDGE}}/recipes.css` → 项目补充 `app.css`（不引 `base.css`，桥接自带标题字号 / 行高 / 字重、按钮继承字体这些基础规则）。桥接与配方是上游只读快照 / npm 包，不改；页面 `<style scoped>` 与 `app.css` 只引用 token 变量（`--color-*`、`--spacing-*`、`--space-*`、`--text-*`、`--control-*`、`--radius-*`、`--border-*`、`--elevation-*`），不写色值与像素字面量。像素只允许出现在按内容定的宽度（表格列宽）上。
- **桥接按 DESIGN 与效果预览逐组件接管**：Element 的 `--el-*` 变量与写死的主色 / 焦点 / 色表都接到语义 token 上，尺寸、字号、圆角、选中态与效果预览一致（分段类是灰轨道上的白块，其余选中走主色系）；已在 Element Plus 2.14 上用完整项目实测过（种子仓库 `morganite/testbed/mall-ops`）。接入后挂走查页 `{{IMPORT}}/vue/KitchenSink.vue` 到 `/kitchen`，亮 / 暗两种模式下逐组件看一遍 hover / focus / disabled。
- **页面骨架与页面形态用配方类，不自己重写**（`recipes.css`）：每页自上而下是顶栏 → 页头 → 可选标签 / 筛选 → 业务内容。壳层 `.app/.sidebar/.topbar`（顶栏左侧统一放 `el-breadcrumb`，工作台也是，分隔符由桥接画成细箭头、`separator="/"` 照传；头像区 `<button class="user">` + `.avatar`）、页头用配方组件 `PageHeader`（`title` / `subtitle`，`#status` 放标题旁的状态胶囊，`#actions` 放页面级操作；每个一级页面一个，副标题没必要就不传），看板页在 H1 下用 `SectionHeader` 分板块（H2 + 右侧只管这一板块的筛选），次要分组才用小标签 `.section-label`；块间距全由内容区 `.content` 的 gap 给，页面不自己加 margin-top；看板 `.board` + 看板卡 `<el-card class="flat panel">`、两栏 `.two-col`、纵向堆叠 `.stack`、卡片栅格 `.card-grid`、设置行 `.setting`、横向表单 `.hform`、附件行 `.file-row`、登录页 `.login*`、图例 `.legend` / 占比列表 `.alloc-list` / 目标进度 `.goals`（分类色 `.c1–.c6`）、筛选栏 `.filter`（控件宽度 `.w-search` / `.w-select` / `.w-date`）、状态胶囊 `.status.*`、操作胶囊 `.act`（一组放进 `.act-group`）、表单页 `.form-page`（只给单列竖向表单）、统计卡 `.stats`；配方组件在 `{{IMPORT}}/vue/*`（PageHeader / SectionHeader / StatCard / EChart / TrendChart / TableSkeleton / ConfirmBar），图表主题来自 `{{IMPORT}}/echarts`（运行时读 token）；柱子端头由 EChart 容器套 `withBarEnds`，不经容器直接 `echarts.init` 的图表，option 自己先过 `withBarEnds`。
- **Element 用法约定**：表格放进 `<el-card class="flat">` 贴边（首尾列自动让出卡片内边距），勾选列宽 48；卡片顶部的 `el-tabs` 自动当卡片标题头：标签与卡片内边距对齐、与带标题的卡片头同高、底线贯穿卡片，不用另加类；直接放在内容区、只切换下方内容的 `el-tabs`（pane 留空）下边距自动归零，只剩一个标签时整个标签栏 `v-if` 掉；步骤条用 `finish-status="success"`（已完成显示勾）、不加 `align-center`（桥接排成效果预览的横排）；通栏按钮 `class="is-block"`；弹窗 `class="is-sm"`（确认）/ `"is-md"`（表单）并 `append-to-body`；金额、日期列 `class-name="num"`（正文字体 + 等宽数字），单号包 `.mono`；统计数字用 `el-statistic` 或 `StatCard`（D-DIN-PRO）。
- **图标**：IconPark 在根组件 `setup()` 里 `IconProvider({ ...DEFAULT_ICON_CONFIGS, ...iconParkDefaults })`（`{{IMPORT}}/iconpark.config`），尺寸 / 颜色用 `.i-icon--*` 类，不在图标上写 size / fill / stroke-width；`main.js` 里 `app.mount()` 之后调一次 `mergeIcons()`（`{{IMPORT}}/icon-merge`）。描边由桥接按屏幕上的 `icon.stroke.width`（1.4px）画，`mergeIcons()` 把每只图标的多段描边合并后一次上色——不调的话，半透明的图标色在描边交叠处会叠深一块。
- **页面状态与权限**（DESIGN「页面状态与权限」）：加载用 `TableSkeleton`（列宽与真实表格一致），空用 `.empty`（插图 + 一句说明 + 至多一个主操作），区域出错用 `.error-box` + 重试按钮，无权限的地址进 403 结果页 `.result`；按角色禁用的按钮外包一层 `<span>` 挂 `el-tooltip` 写明缺的权限（禁用按钮不触发悬停），只读角色用只读态。
- **另一模式**：按 `design-system/theme-map.json` 的激活方式切换（class 激活 = `<html class="dark">`）；不要引 Element 的 dark css-vars。
