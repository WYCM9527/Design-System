# 实测报告 · 拾光商城运营后台

> 用一个完整的 Vue 3 + Element Plus 运营后台检验 Morganite：页面能不能只靠配方和桥接搭出来，搭出来与效果预览是否一致，验收能不能过。产品设定见 `PRD.md`。记录格式同 `element-lab/FINDINGS.md`：是谁的问题、修在哪一层、修了没有。
>
> 首测 2026-10-10（Morganite 0.1.3），问题分 A–F 六类，其中需要决定的请用户拍板；2026-10-11 按拍板结果修进种子（0.1.4），项目改用配方后复测，见「复测」一节。每一条的处理结果写在各节表格里。

技术栈：Vue 3.5 + Element Plus 2.14.7 + vue-router 5 + ECharts 6 + IconPark 1.4 + Vite 8。接入：`ds.mjs init --stack element-plus`，快照换成指向种子的符号链接，依赖锁版本。验收：citrine-accept（清单 `app/accept.config.mjs`），外加一个对照脚本，逐个角色比较效果预览与本项目的计算样式。

## 覆盖面

- 14 个业务页，加上 403 / 404 / 500 / 建设中和组件走查页。
- 50 个页面状态：加载、空、出错、无权限、只读、校验失败、弹窗 / 抽屉打开、不同页签与视图。
- 四个角色：管理员、运营、客服、财务。
- 验收范围：亮 / 暗 × 50 个状态全量扫描；三端 16 页（992 侧栏折叠、390 侧栏抽屉）；4 页 Tab 焦点遍历；组件走查 618 个元素。
- 对照效果预览：工作台、列表、详情、表单、设置、登录、空状态七类页面，约 90 个角色。

首测结论：所有页面都能用配方加桥接搭出来，验收工具链也能跑通。问题集中在 **Element 桥接与效果预览差得明显**：表格字号与边距、侧栏项高、标签页、步骤条、勾选控件尺寸、分页都不一样，其中十几处直接违背 DESIGN 明文。预览里有十几个形态配方没有，项目只能先照预览写在 `app.css`「待提案」区或页面里。

复测结论：桥接按 DESIGN 与效果预览改完，预览里的形态收进配方，项目层样式 `app.css` 现在一条规则都没有，页面里也不再有照预览写的副本。验收全部通过。

页面扫描的「小命中区」362 条只作提示，不算失败，复测数量不变。其中大多数是配方操作胶囊 `.act`，高 22px（`control.height.xs`），低于 `control.hit-min`（24px）；它们横向间距足够，符合 WCAG 2.5.8 的间距例外。首测以为要修的 Element 可关闭标签的 ×（B14）其实早有伪元素把命中区扩到 24px，扫描量的是元素自身的盒子。

## 复测（2026-10-11，Morganite 0.1.4）

种子的改动逐条见 `seeds/morganite/CHANGELOG.md` 0.1.4。项目这边：

- `app.css` 的「待提案」区整段删除；登录、设置两页的 `<style scoped>` 删空，工作台、订单详情、商品表单删掉照预览写的副本。页面用到的类都能在配方里找到。
- 跟着新配方改写法：操作列容器 `.ops` 改名 `.act-group`；卡片顶部的标签页不再加类，桥接会让扁平卡片里贴顶的标签栏自动缩进；登录按钮用通栏按钮 `.is-block`；订单详情步骤条加 `finish-status="success"`；进度条去掉写死的 `:stroke-width`；勾选列宽 44 改 48；商品表单的上传提示改用 `.sub`（原来的 `.help` 带外边距，上传区高了 4px）。

修完重跑对照脚本，又查出四处，都已修：

| 部位 | 差异 | 原因与修法 |
| --- | --- | --- |
| 卡片标题 | 比预览高 3px | Element 入口不引 `base.css`，标题行高跟着正文走。桥接补齐 `base.css` 的标题字号、行高、字重 |
| 带勾选列的表头 | 高约 6px | Element 把勾选格写死成 23px 高的行内 flex，还压在基线上。桥接改成块级、高度随内容 |
| 标签页、侧栏分组标题 | 各高 2px | 预览的标签是按钮（行高 normal），分组标题用正文行高。桥接照改，标签页高度现在正好 44 |
| 效果预览的上传区（新建交易页） | 标题 12px 黑字，与配方不同 | 预览里上传区是表单字段下的 label，被预览自己的 `.field > label` 规则压了。预览排除上传区，回到配方的 14px、`text.secondary` |

剩下的差异不改：

- 写法不同、渲染相同：Element 用 box-shadow 画输入框边线，内边距在 `.cell` 上而不是 `td` 上，按钮靠内边距撑高；预览分别用 border、`td`、固定高度。
- 表格行高差 0.4–1px，是边线取整。
- 描述列表里用等宽数字的值比预览高 2px（等宽字体的行框更高），看不出来。
- 数据内容不同，比如分页总数「共 42 条」与「共 128 条」。

## 复现

```bash
cd morganite/testbed/mall-ops/app
npm run build && npx citrine-accept pages      # 页面扫描（亮暗 × 50 状态）
npx citrine-accept components                  # 组件走查
npx citrine-accept narrow && npx citrine-accept focus
node ../../../../design-system-adopter/scripts/ds.mjs status          # 快照完整性、本地修改、上游版本
node ../../../../design-system-adopter/scripts/ds.mjs upgrade --dry-run
```

角色演示参数写在 `#` 前面：`?role=ops|service|finance`、`?theme=dark`、`?state=loading|empty|error`，例如 `?role=finance#/orders` 进 403。页面状态的完整清单见 `accept.config.mjs` 的 `PAGES`。
