# 拾光商城 · 运营后台 — 产品文档（设计系统实测版）

> 这是一份**虚拟**产品文档，唯一目的是给 `seeds/morganite`（Morganite 玫瑰金）提供一个足够真实的完整实测项目：用一家电商的日常运营把中后台常见的页面类型、组件与状态都走一遍，检查设计系统在真实 Element Plus 项目里是否够用、是否与效果预览一致。业务数字、名称、流程都是编的，不要在其他场景引用。
>
> 版本 0.1 · 2026-10-10 · 配套 Morganite 0.1.3。评判顺序见 `morganite/README.md`「以什么为准」：规范（token + DESIGN）→ 视觉基准（效果预览 `previews/rose-gold-admin/`）→ 本项目只做落地验证，不一致就修桥接或配方。

## 1. 产品定位

拾光是一家卖首饰、腕表与生活方式小物的品牌电商，渠道有小程序、App、天猫与抖音。运营后台给内部四类同学用：处理订单与物流异常、审核售后退款、上架与维护商品、做会员运营与营销活动、看经营数据。典型的「多表、重表单、要看图表」中后台，桌面为主（1440 / 1920 宽），也要能在 13 寸笔记本（窄屏）和手机上临时处理事情。

四个角色（角色决定菜单可见性与按钮权限，是唯一的权限维度）：

| 角色 | 能做什么 | 用来测什么 |
| --- | --- | --- |
| 管理员 | 全部 | 完整菜单 |
| 运营 | 工作台、订单、商品、客户、营销、消息、设置；不能审核退款，看不到报表结算与成员 | 按钮级禁用 + Tooltip 说明原因；访问成员页 → 403 |
| 客服 | 工作台、订单（查看、备注、发起售后）、售后、客户（只读）、消息、设置 | 缩短的菜单；打开商品编辑页 → 全部只读 |
| 财务 | 工作台、售后（退款审核）、数据报表（含结算）、消息、设置 | 图表、导出、带合计行的结算表；访问订单 → 403 |

## 2. 范围控制

- 主页面 **14 个**（第一批 6 个、第二批 8 个），另有 403 / 404 / 500 结果页、一个「建设中」模块与组件走查页。每页一个主任务。
- 表单单屏字段数 ≤ 14；多步只出现一次（商品编辑用分区卡片，不做向导）；不做拖拽、实时推送、地图、富文本。
- 列表页四种非正常状态（加载中 / 空 / 出错 / 无权限）在订单列表**完整实现**一次，其余列表各挑一两种复用同一配方。
- 弹层四种：确认弹窗（`layout.modal.width.sm`）、表单弹窗（`.md`）、详情 / 操作抽屉（`layout.drawer.width`）、下拉菜单；每种在文档里规定一次，其他地方引用。
- 图表五种：折线、柱状、环形、排行条、热力格。
- 亮 / 暗两种模式与三端（桌面 / 窄屏 992 侧栏折叠 / 手机 390 侧栏抽屉）是全局要求，不是页面功能：每页都要在这几种组合下成立。

## 3. 全局框架

### 3.1 布局

- 与效果预览同一壳层：左侧白底侧栏（`layout.sidebar.width`，窄屏折叠到 `layout.sidebar.collapsed-width`，手机收成抽屉）；顶栏白底（`layout.topbar.height`）；内容区四周 `space.gutter`。
- 顶栏从左到右：工作台显示问候语（日期 + 「欢迎回来，林夏」），其余页面显示面包屑（最多三级，详情页可点回列表）· 胶囊搜索（占位「搜索订单号 / 商品 / 客户」）· 通知铃铛（未读红点计数）· 暗色切换 · 头像下拉（个人设置 / 切换角色（测试用）/ 退出登录）。
- 侧栏三组：**概览**（工作台、数据报表）、**交易**（订单管理、售后退款、商品管理、库存盘点、客户管理、营销中心）、**系统**（消息中心、成员与角色、系统设置、组件走查）。当前项按 DESIGN：亮色主色底块 + 白字白图标，暗色金色暗底 + 亮金字；侧栏里不放计数气泡，待处理数放在工作台与列表页的状态条上。

### 3.2 全局状态

| 状态 | 出现位置 | 规格 |
| --- | --- | --- |
| 加载中 | 列表首屏、图表 | 按目标形状的骨架（表格用 `TableSkeleton`，卡片 / 图表用骨架块）；提交中的按钮转圈并禁用 |
| 空 | 列表筛选无结果、待办为空 | 配方 `.empty`：插图 + 一句话 + 一个恢复动作（「清除全部条件」） |
| 出错 | 接口失败 | 卡片内错误条（配方 `.error-box`）+ 「重试」；不弹全屏 |
| 无权限 | 直接访问无权页面 / 无权按钮 | 403 结果页（配方 `.result`）；无权按钮禁用并带 Tooltip「需要 xx 权限」 |
| 成功反馈 | 保存、提交、删除 | 顶部居中的轻提示，3 秒消失 |
| 需要注意 | 库存告急、活动预算将尽 | 页面顶部提示条（`el-alert`），可关闭，右侧导览链接 |

### 3.3 通用表格

- 每页 20 条，可切 10 / 20 / 50；可排序列显示排序指示；首列勾选 + 末列「操作」固定。
- 行内操作是操作胶囊 `.act`，最多两个，多余的收进「更多」下拉；危险动作 `.act.danger`，不可用的保留位置、压淡并用 title 说明原因。
- 选中 ≥ 1 行时出现批量条（配方 `.batch`：已选 N 项 · 批量动作）；选中行与悬停同色。
- 状态列是状态胶囊 `.status.*`，类别列是中性标签 `.tag`；金额、时间列 `class-name="num"`（正文字体 + 等宽数字，金额右对齐）；单号 `.mono` 链接。
- 筛选栏（配方 `.filter`）：条件在左，「重置（文字按钮）→ 查询（次要按钮）」在右；已选条件以筹码 `.chip` 显示在下方，可逐个移除、可「清除全部」；按状态的快捷筛选用状态条 `.stat-strip`。

### 3.4 通用表单

- 业务表单是两列竖向标签（配方 `.form-grid`，长字段 `.span2` 占整行），按「基本信息 / 价格库存 / …」分区，每区一张卡片；设置类表单是横向标签（标签列 `layout.form.label-width`）。
- 必填星号在标签前；失焦校验，错误文案在字段下方，帮助文字（`.help`）与错误不同时出现；提交时滚到第一个错误。
- 只读字段用只读块（配方 `.ro`），禁用字段整体 `opacity.disabled`。
- 长表单底部操作条贴底跟随（`.form-foot.is-sticky`）：取消 / 保存草稿 / 提交；每屏只有一个主按钮。
- 弹窗与抽屉的宽度只用 `layout.modal.width.sm / md` 与 `layout.drawer.width`。

## 4. 页面清单 · 第一批

### 4.1 登录

**目标**：进入系统。全站唯一一处大面积品牌面（`color.bg.brand` + `color.text.on-brand`）。

- 与效果预览登录页同构：左侧品牌面（Logo、两行标语、一句副标题、品牌名），右侧登录卡：账号密码 / 手机验证码两个页签、「7 天内自动登录」、忘记密码、大号登录按钮、企业微信 / 钉钉两个次要按钮、协议脚注。
- 状态：字段为空 → 字段下方错误；密码错误 → 卡片顶部错误提示条（`?state=error`）；登录中 → 按钮转圈禁用。

### 4.2 工作台

**目标**：一屏看到今天要处理的事。

- 顶栏显示问候语；页面顶部一行「经营概览」分区标签 + 统计周期分段选择（今日 / 本周 / 本月）+ 导出 + 主按钮「发布商品」。
- 四张统计卡（`StatCard`）：今日销售额、支付订单数、客单价、退款率（退款率下降是好事：向下箭头 + 绿色）。
- 销售趋势折线（近 14 天，本期 / 上期两条线）+ 待办列表（6 条，每条状态胶囊 + 时间 + 导览箭头）。
- 热销商品排行条（前 8，前三名金色）+ 渠道占比环形图 + 月度目标进度（三条进度条：品牌色一条、中性两条）。
- 最近订单精简表（5 行：单号、客户、商品、状态、金额），卡片头「查看全部」导览链接。
- 状态：`?state=loading` 统计卡与图表骨架、表格骨架；`?state=empty` 待办空态「今天没有待办」。

### 4.3 订单管理（列表）

**目标**：找到一单并处理它。**表格规格的完整实现处。**

- 页头：标题 + 一句说明 + 导出 / 主按钮「手工建单」。下方状态条：全部 / 待发货 / 已发货 / 物流异常（带数量，可点切换）。
- 筛选栏：关键词（单号 / 客户 / 手机号）、渠道下拉、状态下拉、下单时间范围；重置 / 查询。筹码显示已选条件。
- 表格列：勾选 · 订单号（等宽链接，副行显示渠道与客户）· 商品（首件名 + 「等 N 件」）· 渠道（中性标签）· 下单时间（可排序）· 实付金额（右对齐、可排序）· 状态 · 操作（详情 / 发货 · 更多 ▾：改地址、取消订单）。首列与操作列固定。
- 状态词汇：待付款（neutral）、待发货（warning）、已发货（info）、已完成（success）、已关闭（neutral）、物流异常（error）。
- 批量条：批量发货、导出所选、批量关闭（危险，需「关闭订单」权限）。
- 四种非正常状态在此页完整实现：`?state=loading` 骨架、`?state=empty` 空态、`?state=error` 错误条、`?role=finance` 访问即 403。
- 「取消订单」走确认弹窗（标题、一句后果、「再想想」/ 危险按钮「确认取消」），关闭后焦点回到触发按钮。

### 4.4 订单详情 + 发货抽屉

**目标**：看清一单的全部信息并发货。

- 页头：标题 = 订单号 + 状态胶囊；副行：下单时间 · 渠道 · 客户；动作：复制单号 / 修改地址 / 更多 ▾（打印发货单、关闭订单）/ 主按钮「发货」。
- 处理进度步骤条：下单 → 支付 → 发货 → 签收（完成步、当前步、未开始三态；已关闭订单当前步变成「已关闭」并标出中止）。
- 两栏：左侧订单信息描述列表（收货人、手机、地址（长文本测多行）、支付方式、实付、优惠、备注）；右侧处理记录时间线（当前 / 异常 / 普通三种节点）。
- 页签：商品明细（表格 + 合计行）/ 物流轨迹（时间线）/ 操作日志（空态）。
- **发货抽屉**（`?drawer=ship`）：物流公司（下拉）、运单号（必填，格式校验）、发货仓（单选）、通知客户（开关）；底部取消 / 确认发货；成功后提示并更新状态。
- 状态：`?state=closed` 已关闭订单；不存在的单号显示内容级空态（不是 404 页）。

### 4.5 商品管理（列表）

**目标**：找到商品并上下架。

- 页头 + 状态条（全部 / 在售 / 库存告急 / 已下架）+ 顶部提示条「6 个商品库存低于安全线」。
- 筛选栏：关键词（名称 / 货号）、类目（级联）、价格区间（两个数字框）、上架状态；视图切换（列表 / 卡片，分段选择器）。
- 列表视图列：勾选 · 商品（缩略图 + 名称 + 货号副行）· 类目（标签）· 售价（右对齐）· 库存（低于安全线时数字用警示色 + 「告急」胶囊）· 30 天销量 · 上架（开关，需要编辑权限）· 操作（编辑 / 复制 · 更多：删除）。
- 卡片视图（`?view=card`）：每张显示缩略图、名称、价格、库存、状态胶囊、上架开关——同一数据两种密度。
- 批量条：批量上架、批量下架、批量改价。
- 状态：`?state=loading` 骨架。

### 4.6 商品编辑（新建 / 编辑表单页）

**目标**：录入一个商品并提交审核。**表单规格的完整实现处。**

- 分区卡片：**基本信息**（商品名称*、货号（编辑时只读块）、类目*（级联）、品牌（下拉）、材质（多选标签）、卖点（多行，字数提示））· **价格与库存**（售价*、划线价、成本价（仅管理员可见）、库存预警线（数字步进）、规格明细——行内可编辑的 SKU 表格：规格、售价、库存、条码，可增删行）· **图片与详情**（主图上传区 `.upload-zone`、详情说明多行）· **物流与售后**（运费模板单选、支持 7 天无理由（开关）、上架时间（立即 / 定时 + 日期时间））。
- 底部贴底操作条：取消 / 保存草稿 / 提交审核。
- 校验演示（`?state=invalid`）：名称必填、售价为负、SKU 条码重复三种错误同屏出现一次，提交时滚到第一个错误。
- 客服角色打开编辑页（`?role=service`）：全部字段只读，底部只剩「返回」。

## 5. 页面清单 · 第二批

### 5.1 售后退款（列表 + 审核弹窗）

- 列表：售后单号、关联订单、客户、类型（仅退款 / 退货退款 / 换货，标签）、退款金额、原因（单行截断）、申请时间、状态（待审核 warning、处理中 info、已退款 success、已驳回 error、已撤销 neutral）、操作（审核 / 详情）。
- **审核弹窗**（表单弹窗，`?audit=1`）：只读摘要（描述列表）+ 审核结论（单选：同意退款 / 驳回）+ 驳回原因（选驳回才出现，必填多行）；运营无审核权限时「审核」按钮禁用并说明。
- 状态：`?state=empty` 空态。

### 5.2 客户管理（列表）

- 筛选：关键词、会员等级、注册渠道、最近消费时间；人群快捷筛选（分段：全部 / 高价值 / 沉睡 / 新客）。
- 列：客户（头像 + 昵称 + 手机打码副行）、会员等级（黑金用强调徽标 `.badge.brand`，其余中性标签）、累计消费（右对齐）、订单数、最近下单、标签（最多两个 + 「+N」）、状态（正常 / 已冻结）、操作（详情）。

### 5.3 客户详情（多页签）

- 页头：头像 + 昵称 + 等级徽标；副行：注册时间 · 渠道；动作：发券 / 加标签 / 更多（冻结账户：危险确认）。
- 一行四个统计卡：累计消费、订单数、客单价、积分余额。
- 页签（`?tab=`）：基本资料（描述列表）/ 订单记录（精简表格）/ 积分流水（时间线）/ 优惠券（卡片列表，已用 / 过期压淡）/ 跟进备注（空态 + 新增）。

### 5.4 营销中心（活动 + 优惠券）

- 两个页签：**活动**、**优惠券**（`?tab=coupons`）。
- 活动列表：活动名、类型（满减 / 折扣 / 秒杀 / 赠品）、渠道、预算 / 已用（进度条，预算用尽 90% 以上标警示）、时间、状态（草稿 / 待审核 / 进行中 / 已结束 / 已下线）、操作（编辑 / 上线 · 下线 / 复制）。
- 视图切换列表 / 卡片（`?view=card`）。
- **新建活动弹窗**（`?dialog=1`）：活动名称*、类型*（单选按钮组）、规则（满 X 减 Y 两个数字框）、预算上限*（负数校验示例）、投放渠道（多选，显示为标签）、活动时间*（范围）、同步首页 Banner（开关）、结束自动下线（开关）。
- 优惠券：券名、类型、面额 / 门槛、已领 / 总量（进度）、有效期、状态；「发放」打开小弹窗（选人群 + 数量）。
- 上线 / 下线走确认弹窗。

### 5.5 数据报表

- 顶部：统计周期分段（近 7 天 / 近 30 天 / 自定义）+ 日期范围 + 渠道筛选 + 导出。
- 四张统计卡；销售额折线（三个渠道三条线，分类色 1–3）· 类目销售柱状图（饱和度渐变，上浅下深）· 渠道占比环形图（分类色 1–5）· 商品排行条（前 10）· 下单时段热力（7 天 × 24 小时，顺序色 1–5）。
- 财务 / 管理员可见「结算」页签（`?tab=settlement`）：带合计行的结算表 + 导出。

### 5.6 消息中心 + 公告详情

- 页签：全部 / 订单 / 审核 / 系统；每条：类型图标、标题、摘要单行截断、时间、未读圆点；「全部标为已读」。
- 公告详情：大标题、发布人与时间、正文 6–8 段（小标题、有序列表、表格、引用）——全站唯一的长文页。

### 5.7 系统设置

与效果预览的系统设置同构：页签 个人资料（横向表单）/ 通知（设置行 + 开关 + 复选 + 下拉）/ 安全（修改密码、两步验证、登录设备、注销账户（危险确认））/ 外观（主题分段与顶栏切换同步、界面密度单选、默认折叠侧栏开关——真的接到壳层）。

### 5.8 成员与角色

- 左右结构：左侧角色列表（四个角色，可新增）；右侧该角色的权限矩阵：按模块分组的勾选框（订单：查看 / 发货 / 关闭；商品：查看 / 编辑 / 上下架 …），组标题带「全选」（半选态）。
- 下方成员表：头像、姓名、账号、角色（标签）、启用（开关）、最近登录、操作（编辑角色 / 重置密码 / 移除（危险确认））。

### 5.9 结果页与建设中

- 403 / 404 / 500：插图 + 标题 + 一句说明 + 「返回工作台」+ 一个情境动作（403「申请权限」、500「重试」）。
- 库存盘点：与效果预览的空状态页同构的「建设中」页。

## 6. 数据与词汇

- 模拟数据确定性生成（刷新不变，截图可复现）：订单 128、商品 48、售后 24、客户 64、活动 12、优惠券 10、通知 30、公告 3、成员 9。
- 状态词汇（全站统一，对应五种状态色）：
  - success：已完成、在售、进行中、已退款、正常、已开启
  - warning：待发货、待审核、告急、待确认
  - error：物流异常、已驳回、已冻结、失败
  - info：已发货、处理中、退款中
  - neutral：待付款、已关闭、已下架、草稿、已结束、已下线、已撤销
- 金额一律 `¥1,286.00`（正文字体等宽数字），时间 `2026-10-09 14:02`，手机号中间四位打码；涨跌绿涨红跌。

## 7. 非功能要求

- 三端：≥ 993 桌面展开侧栏；≤ 992 侧栏折叠；≤ 768 侧栏收成抽屉、筛选栏纵排、表格横向滚动。任何宽度文档级不横向溢出。
- 亮 / 暗随时切换，不刷新页面；首屏按 `?theme=` → 本地记忆 → 默认亮色，不闪。
- 不加载网络字体（D-DIN-PRO 没装时按字体栈回退）。
- 对比度、可访问名称、命中区、焦点按 DESIGN「验收基线」；已批准的例外只认 AUDIT 登记过的。

## 8. 明确不做

多语言、地图、实时推送、拖拽排序、富文本编辑器、多步向导、打印、Excel 在线编辑、数据大屏、紧凑密度（外观页的密度单选只是表单控件演示）。

## 10. 验收方式

1. `npm run build` 通过，steward `guard` 为 `current`。
2. citrine-accept：全部页面状态 × 亮 / 暗的自动扫描（对比度、可访问名称、命中区、溢出、截断、重复 id）、全组件走查（`#/kitchen`）、三端（992 折叠 / 390 抽屉）、Tab 焦点遍历，全部通过；低对比只允许 AUDIT 登记过的例外。
3. 与效果预览逐项比对同类页面：工作台 ↔ 工作台、订单列表 ↔ 交易记录、订单详情 ↔ 交易详情、商品表单 ↔ 新建交易、系统设置 ↔ 系统设置、登录 ↔ 登录、库存盘点 ↔ 空状态。尺寸、内边距、字号、颜色、边线、圆角不一致的，按「规范 → 效果预览 → 本项目」的顺序判断修哪一层。
4. 每个发现记进 [FINDINGS.md](FINDINGS.md)：现象、根因、修在哪一层、修了没有。
