## 二、数据层 / 骨架缺口（及绕过方式）

- **`api.myWeeklyTrend()` 周起点偏移一天**：用 `toISOString().slice(0, 10)` 切日期，在 UTC+8 环境下周一 00:00 变成前一天 16:00Z，六周区间实际是周日→周六，标签显示的是周日日期（工作台趋势 x 轴为 08/02周 … 09/06周，注释写的是"周一为一周起点"）。页面不能改 `data/*`，只记录。
- **TrendChart 不暴露 yAxis 选项**（整数刻度 `minInterval`）：工作台趋势改用 `EChart` + 桥接 `trendLine` / `areaGradient` 自己拼 option。
- **EChart.vue 不监听 `option` 变化**（只在挂载与亮暗切换时渲染）：页面用 `v-if` 等数据就绪后再挂载；挂载后数据变化图表不会刷新。
- **StatCard 的 `note` 依赖 `delta`**，无 delta 时没有副文案位置；指标口径说明只能放 `title`。
- **recipes.css**：`.chips` 没有下内边距（假定其后总跟 `.batch`），无批量条时 chips 会贴到表头，页面补了 `padding-bottom` 并把 `.chips + .batch` 的上边距归零；`.chip .x` 只按 `<span>` 设计，为键盘可达改成 `<button>` 后需自行重置外观并补命中区；DESIGN 定义了「标题型链接」但 recipes 没有公共类（页面各写 `.title-link`）；没有「金额汇总行」「附件卡」「隐藏条件提示」「可点击统计卡」的配方，都在页面 scoped 里写。
- **session.js**：没有"从工作台 query 读取条件"的公共方法，列表页自己解析 `route.query` 与签名；`rememberList` 没有按用户隔离，只靠 `switchUser` 清空（够用）。
- **api.js**：`getApplication` 不判记录级权限（申请人看他人申请由页面判断并走「记录不存在」）；`submitApplication` 不校验草稿完整性（页面按 brief 的三条规则先判）；`listApplications` 的 `mine` 对申请人身份是冗余条件（页面对申请人忽略并隐藏 chip）；`deleteDrafts` 只返回删除数量，不报告被跳过的非草稿。
- **演示 `state=error`**：借用测试工具 `session.failNext.list = true` 注入一次失败，让「重试即成功」自然发生。
- **导出**：`downloadCsv` 只接收 rows，页面要再调一次 `listApplications(pageSize=total)` 拿全量（多一次 200ms 延迟与一次失败注入机会）。
- **`/tmp/lp-console.mjs` 引用的 `golden-admin/tools/lib/cdp.mjs` 不存在**（实际在 `citrine/tools/lib/cdp.mjs`），冒烟时复制了一份改路径的私用脚本；`python3 -m http.server` 在工具 shell 里退出即被回收，需与冒烟命令放在同一条命令里。

## 三、组件库与规则的冲突

- **el-date-picker（daterange）根节点是 fragment**（tooltip 触发层 + 传送的面板），拿不到 scoped 的 `data-v` 属性，页面 class 只能用 `:deep()` 命中；宽度变量 `--el-date-editor-daterange-width` 在 `.el-date-editor` 组件级声明，必须在更近处覆写；且在 flex 容器里默认渲染成 472px（比自身 350 还宽），要显式 `width` + `flex: none`。
- **el-select 把空串当"无值"**显示灰色占位符，与 DESIGN"全部…是真实选项、正文色"冲突 → 用 `all` 哨兵值再映射为空。
- **el-table 固定右列**：内容超宽时以阴影覆盖相邻列；单元格左右内边距 `table.cell.padding-x` = 20px×2 占去大量宽度且页面不能改，1440 设计基准下必须精确控列宽（本页 1202 / 1206）；表头与单元格默认允许换行（`.cell` white-space normal），列宽略窄时单号 / 时间会折成两行，只能靠列宽兜底。
- **el-table `default-sort` 只在挂载时生效**：为了从记忆恢复排序指示，首屏用骨架、表格挂载后不再卸载（后续加载用 `v-loading`）。
- **el-alert 有 description 时标题自动加粗**且字号 13px（`--el-alert-title-font-size`），页面把标题升到 `text.body.size`；图标是 Element 自带 SVG（DESIGN 允许组件内部功能图标保留）。
- **el-dialog `before-close` 只拦 × / Esc / 遮罩**，程序化关闭不经过它；取消按钮要显式走同一 `beforeClose`，才能满足"Esc 与取消同一确认规则"。
- **el-image-viewer 关闭后焦点不回到触发元素**（PRD §6.6 要求浮层关闭后焦点恢复），组件没有 API 可控。
- **el-pagination**：改每页条数导致页码越界时会额外触发 `current-change`，页面用请求序号忽略过期结果。
- **el-timeline-item 默认节点色**走 `--el-border-color-light`（桥接映射为 `border.default`），中性事件的灰点在暗色下偏暗，但仍可辨。
- **el-dropdown 触发元素**沿用 Orders.vue 的 `<a role="button" tabindex="0">`，Element 不会给它可访问名称，需自己写 `aria-label`；下拉危险项依赖桥接约定类 `is-danger`。
- **el-descriptions `label-width`** 可以直接传 CSS 变量字符串（`var(--layout-form-label-width)`），但列宽是 `<colgroup>` 内联 style，不受 token 管理。
- **quiet 文字按钮与危险文字按钮并排**（详情页本人草稿：`删除(danger text)` 与次要按钮同排）：浅红底 + 白底描边 + 黄底主按钮三种形态同排，DESIGN 未规定页头里危险文字按钮的位置。
- **`el-button` 的 `title`** 依赖 Element 把 attrs 透传到根 `<button>`，brief 依赖禁用态下的原生 tooltip 提示「暂无可导出数据」；主流浏览器对禁用按钮会显示 title，但本次未实测悬停效果。
