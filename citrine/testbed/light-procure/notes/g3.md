## 一、只能猜的地方（DESIGN / AGENTS / recipes 未规定，按自己判断决定）

### 通用（三页共用的决定）
1. **筛选下拉「全部…」的值用 `'all'` 哨兵**，查询时映射为空字符串。DESIGN 要求「全部状态」是真实选项、正文色显示，但 api 用 `!f.status` 判「不筛」，值若为 `''` Element 会当作未选只显示灰色占位符。参考实现 Orders.vue 也是 `value="all"`。
2. **筛选控件宽度写在模板行内 style**（下拉 130 / 140 / 150px，日期范围 260px），关键词框用 `--layout-search-width`。DESIGN 明示「列宽与筛选控件宽度不是 token，按内容定」，参考实现同样内联；没有放进 `<style scoped>`（那里禁止像素字面量）。表格列宽同理走 `width` prop。
3. **页头「共 N 件 / 家」= 当前身份可见总数**（`visibleAssets().length`、`db.suppliers.length`），不随筛选变化；筛选结果条数由分页「共 N 条」承担。理由：PRD 把它叫「申请总数」而非结果数，且工作台带入条件后若跟随筛选，标题数字会跳。
4. **两种空态的插图分层**：「没有任何数据」用 IconPark two-tone 品牌插图（Box / Shop / Log），「筛选无结果」用 `FileSearch` 线性 + `icon.muted`。依据 DESIGN「two-tone 只用于品牌时刻；内容级不存在用 muted 线性图标」。前者给创建入口（管理员），后者给「重置筛选」次要按钮。
5. **加载失败框图标用 `Attention`** 而不是参考实现的 `Close`（× 读起来像关闭按钮）。
6. **`state=empty` 只影响首次加载**，并展示「没有任何数据」空态（不是筛选无结果）；`state=error` 用 `session.failNext.list` 注入一次失败，重试即成功；`state=loading` 停在骨架且不发请求。
7. **表格骨架行数 = min(pageSize, 10)**，列宽数组按真实列宽估算，操作列按管理员 / 非管理员两档。
8. **抽屉 footer 一律有「关闭」次要按钮**（键盘用户有明确出口），管理员在只读抽屉里再给一个「编辑」主按钮——先关只读抽屉再开表单抽屉（顺序而非叠层，遵守「同时最多一个浮层」）。brief 未要求，属小幅增补。
9. **`useDirtyGuard` 挂在列表页**：抽屉 / 弹窗里有未保存修改时，路由离开与顶栏身份切换共用同一条确认；AGENTS 只说「有未保存修改的页面」，把列表页内的表单抽屉也算进去。
10. **`?drawer=<id>` 指向无权 / 不存在的记录**时，在抽屉内显示「记录不存在或已被删除」（`FileSearch` muted 线性 + 一句说明），不泄露内容，关闭即回列表。
11. **详情抽屉加载态用 `el-skeleton :rows="8"`**（getAsset 有 120ms 延迟）。DESIGN 说骨架要按目标形状，但没有描述列表骨架组件，用段落骨架顶替。
12. **只读输入框用 `.ro`**（`bg.readonly` + `text.secondary`，MerchantForm 同款）显示「系统生成」/ 实际编号、分配弹窗的只读部门。
13. **`.help` 在页面里补了上外边距**（recipes 的 `.help` 只有颜色和字号）。

## 二、数据层 / 骨架缺口（api.js、session.js、recipes.css、配方组件缺什么，如何绕过）

1. **小弹窗宽度 token 名**：brief 写的 `--size-modal-sm` / `--layout-modal-sm-width`，实际语义名是 `--layout-modal-width-sm`（= `--size-modal-sm` = 420px）。用了语义名，实测 420px。
2. **supplier 状态常量缺失**：constants.js 没有 `SUPPLIER_STATUS`，页面内自定义 `{ true: 启用/success, false: 停用/neutral }`；建议补进 constants 便于报表 / 表单页复用。
3. **recipes 缺口**：没有标题型链接类；`button.link` 没有重置（只给了 `button.act`）；`.chip .x` 只按 `<span>` 设计，没有按钮重置和 `control.hit-min` 命中区；`.help` 无上外边距；抽屉分组小标题 `.drawer-h` 没有公共类（golden-admin 每页各写一份，本项目也只能在页面重复）。以上均在页面 `<style scoped>` 用 token 补写。
4. **工作台带入参数的读取位置**：AGENTS 规定演示参数放 `#` 之前、不用 `useRoute().query`，但工作台带入是业务导航，走 hash 路由 query（`#/assets?mine=1`）。页面同时读 `route.query.mine` 与 `demoParam('mine')`，两处任一为 `'1'` 即生效。集成方对接 Dashboard 时请用 `router.push({ path: '/assets', query: { mine: 1 } })`。
5. **导出没有专用 api**：`listAssets` 只能分页，导出用 `{ ...query, page: 1, pageSize: 100000 }` 取全部；也会经过 `fail('list')` 注入。
6. **`getAsset` 不做记录级权限**（任何 id 都返回），页面按 `can('asset.viewAll') || (status === 'inuse' && userId === session.userId)` 自判；来源申请可见性也要页面读 `db.applications` 自判，没有 `canViewApp(app)` 之类助手。
7. **`saveAsset` 没有字段级错误码**（只有 forbidden / injected），失败只能 toast + 保留输入；`saveSupplier` 的 `duplicate` 有 code，才能落字段。
8. **`assignAsset` / `returnAsset` / `toggleSupplier` 的 `stale` 错误**：页面 catch 后 toast 并刷新列表。
9. **`listLogs` 用 `from` / `to`**，日期范围控件产出数组（清空后为 `null`），页面转换并防空。
10. **日志 `before` / `after` 是整段字符串**，做不到 PRD 例子「资产状态：闲置 → 在用；使用人：— → 林晓」的逐字段对照，只能整段并排展示。若要逐字段，需要 api 记录结构化 diff。
11. **`TableSkeleton` 列宽是像素数组、表格列宽是 prop**，两处需手动对齐，没有从表格列定义自动推导的方式。
12. **`activeMembers()` / `approvedAppsForLink()` 返回 db 引用**，页面用 computed 包一层（不改 db）。
13. **冒烟工具**：`/tmp/lp-console.mjs` 引用的 `golden-admin/tools/lib/cdp.mjs` 已不存在（现在在 `citrine/tools/lib/cdp.mjs`），本组复制修正为 `/tmp/lp-console-g3.mjs`；另外本机系统代理让无头 Chrome 连 `127.0.0.1` 被拒，需给 Chrome 加 `--no-proxy-server`（用 `CHROME=/tmp/chrome-noproxy-g3.sh` 包装）。集成方统一验证时请注意这两点。

## 三、组件库与规则的冲突（Element Plus 默认行为 / 样式与 DESIGN 打架的地方）

1. **`el-select` 把 `''` 当未选**：模型为空字符串时只显示占位符（`text.placeholder` 灰），与 DESIGN「全部…是真实选项、正文色」冲突 → 用 `'all'` 哨兵。
2. **`el-input-number` 与 async-validator**：`{ required: true }` 不写 `type: 'number'` 会报「不是字符串」；控件清空后模型是 `null` 而不是 `undefined`，规则要同时兜住。
3. **`el-date-picker` 的 `disabled-date` 会静默吞掉手输的被禁日期**（输入 2026-09-20 回车后被清空，看不到字段错误文案），DESIGN 6.4「在错误字段下说明原因」这一条只能靠占位符「不晚于基准日」补足；规则里的兜底触发不到。
4. **`el-form-item :error` 与规则校验共用一个状态**：服务端错误挂上后，用户改字段时不会自动清，需要 `@input` 手动清空，否则错误文字残留。
5. **`el-drawer size` / `el-dialog width` 传 CSS 变量字符串**（`var(--layout-drawer-width)`）可行（实测 480 / 420），但组件类型声明是 number | string，属于「拿变量当字符串」的用法，升级需复扫。
6. **`el-descriptions` 两列在 480 抽屉里放不下**（标签列固定 112px），只能单列；`label-width` 需要字符串 CSS 值。
7. **`el-table @row-click` 会被操作列按钮冒泡触发**，按钮要 `.stop`；表格行不可键盘聚焦，整行可点只对鼠标有效。
8. **`ElMessageBox.confirm` 的确认按钮默认 primary**：危险确认要传 `confirmButtonClass: 'el-button--danger'`（桥接已给 primary + danger 双类补全文字色）；「处理中」不能用 `:loading`，只能 `beforeClose` + `instance.confirmButtonLoading`。
9. **`el-input readonly` 没有只读视觉**：桥接只接了 disabled 的底色，只读需要页面 `.ro` 手动接 `bg.readonly` + `text.secondary`。
10. **`el-button` 禁用时的 `title`** 依赖浏览器对 disabled 元素显示 tooltip（Chrome 可以，部分浏览器不触发鼠标事件）。
11. **`el-skeleton` 是段落骨架**，不符合 DESIGN「按目标形状占位」，抽屉描述列表暂无对应组件。
12. **`el-select filterable` 只按 label 过滤**，要让「按部门搜成员」成立必须把部门拼进 label（「林晓 · 产品设计」）。
13. **`el-timeline-item` 不传 `type` 时节点为默认灰**，与配方一致；但其 `timestamp` 字号 / 颜色由桥接接管，页面里标题与元信息仍需自己按配方写 `text.body-sm` / `text.small muted`。
14. **`el-tabs` 放进抽屉**时头部与内容默认间距为 15px（非 token），页面用 `:deep(.el-tabs__header) { margin-bottom: var(--spacing-4) }` 校正为 16。
15. **`el-input show-word-limit`** 的计数文字用 Element 的 `--el-text-color-secondary`（桥接已接 `text.secondary`），在 `.el-input__wrapper` 内右侧占位，输入较长名称时与文字挤在一起；未额外处理。
