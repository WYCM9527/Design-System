# 轻采 · Agent 规则

## 设计系统（design-system-steward 三行规则）

1. 所有 UI 修改先阅读 `design-system/DESIGN.md` 与当前 Scope／Theme 的登记和说明，只使用已管理的设计决定。
2. 若需求需要新增、修改或跨页面复用的视觉决定，先提出提案；确认后先更新设计系统源、构建并运行 Guard，再实现页面。
3. 不要手改 `design-system/dist/`；一次性差异先作为 Drift 或实验处理，不自动升级为规范。

## 项目接线

- **样式来源**：`src/styles/globals.css` 按顺序引入 Element Plus → `design-system/dist/index.css` → 桥接 `@wycm9527/citrine/bridge/{element-plus.css, iconpark.css}` → 种子配方层 `@wycm9527/citrine/bridge/recipes.css` → 项目补充 `src/styles/app.css`。桥接与配方组件来自 npm 包（仓库内 `file:` 链接种子），项目里没有副本；`design-system/` 由 design-system-adopter 升级（`ds.mjs status / upgrade`，清单 `.adopter.json`；`design-systems/citrine` 是只读上游快照）。页面 `<style scoped>` 只引用 token 变量（`--color-*`、`--spacing-*`、`--space-*`、`--text-*`、`--control-*`、`--radius-*`、`--border-*`、`--elevation-*`…），不写色值与像素字面量。
- **页面骨架用配方类，不自己重写**（recipes.css）：壳层 `.app/.sidebar/.topbar/.iconbtn/.avatar`；页头 `.page-head > div > h1 + p` + `.actions`；卡片 `<el-card class="flat">` + `.card-head > h2 + .right`；筛选栏 `.filter > .conds + .acts`，条件标签 `.chips > .chip > .x`，批量条 `.batch > … + .right`，分页 `.pager`；表单页 `.form-page` + `.form-grid`（`.span2` 跨两列）+ `.form-foot`（长表单加 `.is-sticky`），字段说明 `.help`（出错时自动隐藏），只读字段 `.ro`，行内录入表格 `.table-editable`，上传区 `.upload-zone`；抽屉分组标题 `.drawer-h`；状态胶囊 `.status.{success|warning|error|info|neutral}`（tone 来自 `constants.js` 的 `APP_STATUS / ASSET_STATUS / ACTIVE_STATUS / FILE_STATE`），强调徽标 `.badge.brand`；标题型链接 `.title-link`；副行 `.sub`，涨跌 `.up/.down`，数字 `.num`，单号 `.mono`；空态 `.empty > .illu + b + span`，加载失败 `.error-box`（含重试按钮）；结果页 `.result`；图表容器 `.chart` / `.chart.tall`；统计卡网格 `.stats`，状态条 `.stat-strip > .cell`。
- **链接分四层**：内容型 `.link`（单号 / 名称：斜体下划线，单号加 `.mono` 不斜体）、操作型 `.act`（查看 / 编辑 / 提交 / 分配等动词：同色胶囊描边，`<a>`/`<button>` 同形，相邻直接并排，危险加 `danger`，不可用用 `<button disabled title="原因">`；不要另写字号字重）、导览型 `.go`（查看全部：文字 + `<Right class="i-icon--sm" />`）、标题型 `.title-link`（列表项标题：近黑 + 500）。表格操作列默认操作胶囊；审批「通过 / 驳回」这类决定用 `el-button`（quiet 文字按钮 / 危险文字按钮）。
- **组件**：Element Plus（桥接已接 token，不要改桥接、不要引 Element 的 dark css-vars）。统计卡 `@wycm9527/citrine/vue/StatCard.vue`（label / value / delta / up / positive / note / hint），图表 `EChart.vue`（`:option="(t, echarts) => ({...})"`，只写数据与布局，颜色线型来自主题；option 里读到的响应式数据变了会自动重画）与 `TrendChart.vue`（days / series / count；计数型自动整数刻度、从 0 起），排行柱 `rankBars()`（`@wycm9527/citrine/echarts`），表格骨架 `TableSkeleton.vue`（rows / cols）；确认弹窗一律用 `@wycm9527/citrine/vue/confirm.js` 的 `confirmBox / confirmDanger`（关闭后焦点回到触发按钮），不直接用 `ElMessageBox.confirm`。弹窗尺寸用类 `el-dialog.is-sm / .is-md`。IconPark 图标尺寸类 `i-icon--xs|sm|md|lg|xl|2xl`，独立图标颜色 `i-icon--muted`；图标按钮必须有 `title` 或 `aria-label`。
- **数据层**（`src/data/`）：`constants.js`（状态 → 文案 + 胶囊语义 tone、角色、限制）、`db.js`（reactive 数据库 + 持久化、`now()` 演示时钟、`nextNo()`）、`api.js`（全部业务操作，异步，抛 `ApiError`）、`session.js`（当前身份 `user` / `role` / `can(perm)` / `canSee(menu)`、列表记忆 `rememberList/recallList`、演示参数 `demoState()`）、`format.js`（`money / dateOf / timeOf / dash / sumLines / downloadCsv / fileSize`）、`files.js`（附件 IndexedDB：`putFile / getFile / deleteFile / fileUrl / validateFile / newFileId`）、`guard.js`（`useDirtyGuard(isDirty)` / `confirmLeave()`）。页面不直接改 `db`，只读 `db` 用于下拉选项等。
- **列表页约定**：下拉「全部…」的值用 `'all'` 哨兵（Element 把空串当未选），查询时映射为空；工作台带入的业务条件走 hash 路由 query（`#/assets?mine=1`，页面读 `route.query`），与 `#` 之前的演示参数分开；`pageSize` 初值取 `db.settings.pageSize`；筛选 / 页码 / 排序在查询后 `rememberList(key, state)`，`onMounted` 先 `recallList(key)` 恢复；更换排序或条件回第一页；删除后当前页为空退到上一页；总条数、分页用 `el-pagination`（`layout="total, sizes, prev, pager, next"`，`:page-sizes="PAGE_SIZES"`）；工作台带入的条件显示为可移除 `.chip`；加载中用 `TableSkeleton`，失败用 `.error-box` + 重试并保留筛选，无数据区分「没有任何数据（给创建入口）」与「筛选无结果（给重置筛选）」。
- **三端**（DESIGN「三端」）：窄屏 ≤1280（PRD 覆盖）侧栏默认折叠；手机 ≤768 侧栏离屏抽屉（壳层 `navOpen` + `.menu-btn` / `.sidebar-mask` / `.collapse-btn`，`el-menu :collapse="collapsed && !isMobile"`）；浮层 / 分页 / 面包屑的手机形态由桥接与 recipes 接管，页面不自己写媒体查询。
- **演示状态参数**（截图脚本依赖）：`?state=loading|error|empty|invalid|success|missing`、`?tab=`、`?user=u04`、`?role=applicant|approver|admin`、`?theme=dark` 放在 `#` **之前**，页面用 `demoState()` / `demoParam('tab')` 读取（不要用 `useRoute().query`）。`state=error` 表示首次加载失败一次，`loading` 表示停留在骨架。
- **权限**：菜单可见性由路由 `meta.menu` + `canSee` 控制；按钮级用 `can('approve' | 'asset.manage' | 'supplier.manage' | 'org.manage' | 'settings.manage' | 'logs.view' | 'export' | 'app.viewAll' | 'asset.viewAll')`；记录级（本人草稿、无权记录）由页面判断，无权查看的记录显示「记录不存在或已被删除」而不泄露内容。
- **表单**：`el-form` + `rules`，提交时 `validate` 失败 `scrollIntoView` 到首个错误；必填用 Element 的 `required` 星标；保存 / 提交中按钮 `:loading`，失败 `ElMessage.error` 并保留输入；成功提示写具体结果（「资产已分配给林晓」）。有未保存修改的页面用 `useDirtyGuard`。抽屉 / 弹窗：`el-drawer` / `el-dialog`，`:close-on-click-modal="false"`，脏状态下 `before-close` 走原位确认条（`useInlineConfirm().ask(...)` + 页脚里 `<ConfirmBar v-if="leave.state.open" …>`），不在浮层里再弹 `confirmLeave`。
- 改完 UI 运行 `node ../../../../skills/design-system-steward/scripts/guard.mjs --project "$PWD"`，应为 `current`；`npm run build` 无报错。
