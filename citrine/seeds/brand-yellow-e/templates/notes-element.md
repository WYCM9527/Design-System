- **样式来源**：样式入口按顺序引入 Element Plus → `design-system/dist/index.css` → 桥接 `{{BRIDGE}}/{element-plus.css, iconpark.css}` → 配方层 `{{BRIDGE}}/recipes.css` → 项目补充 `app.css`。桥接与配方是上游只读快照 / npm 包，不改；页面 `<style scoped>` 与 `app.css` 只引用 token 变量（`--color-*`、`--spacing-*`、`--space-*`、`--text-*`、`--control-*`、`--radius-*`、`--border-*`、`--elevation-*`…），不写色值与像素字面量。**像素允许出现的位置只有**：组件的宽度类 prop（表格列宽 `width`、下拉 / 输入框的行内 `style="width: …px"`——DESIGN 规定列宽与筛选控件宽度按内容定，不是 token）；颜色 / 字号 / 间距 / 圆角 / 阴影一律 token。
- **页面骨架用配方类，不自己重写**（recipes.css）：壳层 `.app/.sidebar/.topbar/.iconbtn/.avatar`；页头 `.page-head > div > h1 + p` + `.actions`；卡片 `<el-card class="flat">`（自由内容 / 图表用 `.card-body` 拿留白；表格、筛选栏等配方自带内边距） + `.card-head > h2 + .right`；筛选栏 `.filter > .conds + .acts`，条件标签 `.chips > .chip > .x`，批量条 `.batch`，分页 `.pager`；表单页 `.form-page` + `.form-grid`（`.span2` 跨两列）+ `.form-foot`（长表单加 `.is-sticky`），字段说明 `.help`，只读字段 `.ro`，上传区 `.upload-zone`；抽屉分组标题 `.drawer-h`；状态胶囊 `.status.{success|warning|error|info|neutral}`，强调徽标 `.badge.brand`；副行 `.sub`，涨跌 `.up/.down`，数字 `.num`，单号 `.mono`；空态 `.empty`，加载失败 `.error-box`；结果页 `.result`；图表容器 `.chart` / `.chart.tall`；统计卡网格 `.stats`。

- **配方组件**（`{{IMPORT}}/vue/*`、`{{IMPORT}}/echarts` 这些路径由包 exports 映射到种子的 `bridge/vue/*`、`bridge/echarts.js`，与身份文件 components 指的是同一处）：统计卡 `{{IMPORT}}/vue/StatCard.vue`（label / value / delta / up / positive / note / hint）；图表 `EChart.vue`（`:option="(t, echarts) => ({...})"`，只写数据与布局，颜色线型来自主题）与 `TrendChart.vue`（days / series / count），排行柱 `rankBars()`（`{{IMPORT}}/echarts`）；表格骨架 `TableSkeleton.vue`；页面级确认弹窗一律用 `{{IMPORT}}/vue/confirm.js` 的 `confirmBox / confirmDanger`（不直接用 `ElMessageBox.confirm`）；抽屉 / 弹窗内的离开确认用原位确认条 `ConfirmBar.vue` + `inlineConfirm.js`（不在浮层里再叠弹窗）。弹窗尺寸用类 `el-dialog.is-sm / .is-md`。

- **走查页**：路由挂 `component: () => import('{{IMPORT}}/vue/KitchenSink.vue')` 到 `/kitchen`（不进侧栏），`accept.config.mjs` 的 `KITCHEN: '#/kitchen'`，`citrine-accept components` 就对 600+ 个交互元素做 hover / focus 走查。页面扫描还会审计**静息黄色**：品牌黄只能出现在允许清单内，项目合法位置写进 `YELLOW_ALLOW`。
